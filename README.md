# 🌟 Aura Bot — Настольный ИИ-Компаньон и Физический Аватар

> **Aura Bot** — это не ограниченная заводская игрушка, а автономный локальный ИИ-агент с физическим телом. Он живёт на рабочем столе, видит окружающий мир через камеру, слышит комнатную речь, управляет ПК, обладает долговременной памятью и учится в процессе общения.

---

## 👁️ Философия Проекта

Ключевая концепция Aura Bot — **полное разделение Тела и Мозга**[cite: 5, 6]:
* **Тело (ESP32-S3):** Высокоэффективная аппаратная платформа, отвечающая за сбор сенсорных данных, захват аудио и видео, управление сервоприводами и вывод анимаций мимики на экран[cite: 5, 6].
* **Мозг (Локальный ПК / ИИ-Агент):** Полноценная мультимодальная нейросетевая система, принимающая автономные решения, анализирующая зрение и управляющая операционной системой ПК[cite: 5, 6].

Вдохновение для проекта:
* **Anki Cozmo** — эмоциональность, живость характера и динамическое выражение настроения.
* **AIBI & StackChan** — компактный настольный форм-фактор, открытая архитектура и прямоугольный дисплей-лицо.
* **Jarvis (Iron Man)** — проактивность, контроль над компьютерами, инициатива и адаптивная память.

## 🛠️ Аппаратная Архитектура (Hardware Spec)

Все компоненты подобраны с расчётом на доступность, высокую производительность и исключение конфликтов шин данных[cite: 5, 6].

| Блок | Компонент | Интерфейс / Пины ESP32-S3 | Назначение и Особенности |
| :--- | :--- | :--- | :--- |
| **MCU** | GOOUUU ESP32-S3-N16R8[cite: 5, 6] | 16MB Flash (QIO), 8MB Octal PSRAM[cite: 5, 6] | Центральный микроконтроллер[cite: 5, 6] |
| **Дисплей** | 1.3" IPS 240x240 GMT130 (ST7789)[cite: 5, 6] | SCK: GPIO 39, SDA: GPIO 38, RES: GPIO 40, DC: GPIO 41, BLK: GPIO 48[cite: 6] | Вывод анимированных глаз и эмоций[cite: 5, 6] |
| **Камера** | OV5640 / OV2640 (Длинный FPC шлейф)[cite: 5, 6] | DVP 8-bit Parallel (GPIO 4-11, 15-18)[cite: 6] | Потоковое зрение, Face ID, аналитика стола[cite: 5, 6] |
| **Микрофон** | I2S MEMS INMP441[cite: 6] | SD: GPIO 42, WS: GPIO 1, SCK: GPIO 2[cite: 6] | Дальний захват речи по всей комнате[cite: 5, 6] |
| **Усилитель** | MAX98357A (I2S Class D 3W)[cite: 6] | LRC: GPIO 14, BCLK: GPIO 13, DIN: GPIO 12[cite: 6] | Воспроизведение голоса и звуковых эффектов[cite: 5, 6] |
| **Сервоприводы** | 2 × EMAX ES08MA II (Металл)[cite: 6] | Yaw (Поворот): GPIO 47, Pitch (Наклон): GPIO 21[cite: 6] | 2-DOF механика поворота и наклона головы[cite: 5, 6] |
| **Питание** | Модуль MB102 5V/2A + Конденсаторы 1000мкФ[cite: 6] | Разделение линий 5V для серво и ESP32[cite: 6] | Гашение просадок напряжения и устранение шумов[cite: 5, 6] |

## 🧠 Программная Архитектура и Режимы Работы

```text
                  [Облачные API: Groq / DeepSeek / OpenAI]
                                     ▲
                                     │ (При отключенном ПК)
                                     │
┌──────────────────────────┐      Wi-Fi      ┌───────────────────────────────────┐
│     ESP32-S3 (Тело)      │◄───────────────►│    Сервер ПК (Мозг / OpenClaw)    │
│                          │                 │                                   │
│  • Дисплей ST7789        │  HTTP MJPEG     │  • Porcupine / Wake-Word          │
│  • Камера OV5640         ├─────────────────►  • Faster-Whisper (STT)           │
│  • Микрофон INMP441      │                 │  • Ollama (Qwen 2.5 7B / Llama 3) │
│  • Усилитель MAX98357A   │  WebSocket JSON │  • Piper / XTTS v2 (TTS)          │
│  • 2-DOF Серво-платформа ◄─────────────────┤  • YOLOv8 + Moondream2 (Vision)   │
└──────────────────────────┘                 │  • RAG Память (Obsidian + Chroma) │
                                             │  • Модуль Управления ОС ПК        │
                                             └───────────────────────────────────┘
```[cite: 5, 6]

### Двухрежимная Система
1. **Режим «Супер-Агент» (ПК включен):**
   * **Видеопоток:** Передача QVGA (320x240 @ 15fps) по HTTP MJPEG[cite: 6].
   * **Канал связи:** Постоянный WebSocket для синхронизации аудио PCM 16kHz, координат трекинга и JSON-команд[cite: 6].
   * **Вычисления:** Полноценное использование локальных LLM (Qwen/Llama), базы знаний Obsidian, компьютерного зрения YOLOv8 и автоматизации ОС[cite: 5, 6].
2. **Режим «Автономный Питомец» (ПК выключен):**
   * При таймауте связи >10 секунд происходит автоматическое переключение на прямое подключение к облачным API (Groq / DeepSeek) по Wi-Fi[cite: 6].
   * Мимика и базовая кинематика головы управляются автономными процедурными алгоритмами на ESP32[cite: 5, 6].

## 🎯 Основные Возможности и Фишки

### 1. Живой Голосовой Диалог
* **Wake-Word активация:** Автоматический переход в режим активного слушания по ключевому слову («Джарвис» / «Аура»)[cite: 6].
* **Потоковый TTS:** Озвучка начинается через 1.5–2.5 секунды после окончания фразы благодаря оптимизированным моделям Piper / XTTS v2[cite: 5, 6].
* **Неречевые Звуки:** Использование реакций (вздохи, смех, мурлыканье, звуки R2-D2) для выражения эмоционального состояния[cite: 5].

### 2. Динамическое Зрение и Слежение (Face ID)
* **2-DOF Механика:** Синхронный поворот камеры и экрана за объектом наблюдения[cite: 5].
* **Умный трекинг:** YOLOv8 определяет координаты лица человека, вычисляя углы для сервоприводов Yaw/Pitch и смещения зрачков на дисплее[cite: 6].
* **Распознавание людей:** Робот запоминает новые лица, заносит информацию в `People.md` и проявляет адаптивные эмоции при встрече незнакомцев[cite: 5, 6].

### 3. Долговременная Память (RAG + Obsidian)
* **Markdown База Данных:** Логирование событий, записей о друзьях и обнаруженных предметах прямо в структуру Obsidian Vault (`People.md`, `Objects.md`, `Daily_Logs/`)[cite: 6].
* **Векторный поиск ChromaDB:** Семантическая индексация заметок позволяет подтягивать в контекст нейросети только релевантные факты, предотвращая деградацию диалога[cite: 6].

### 4. Самообучение и Управление ПК
* **Управление ОС:** Переключение музыки, открытие приложений, считывание данных с экрана, регулировка системных параметров[cite: 5].
* **Корректировка сценариев:** Робот может переписывать свои файлы конфигурации на основе голосовых поправок пользователя[cite: 5].

### 5. Поведенческая Матрица (FSM)
* **Ночной режим:** В интервале 23:00–07:00 экран отключается, ШИМ-сигнал сервоприводов снимается для убирания гула, а робот переходит в «глубокий сон»[cite: 5, 6].
* **Проактивное поведение:** Если в комнате долго ничего не происходит, робот периодически оглядывается, вздыхает или напевает короткую мелодию[cite: 5].

## 📁 Структура Репозитория

```text
aura_bot/
├── firmware/                 # Прошивка ESP32-S3 (PlatformIO / C++)
│   ├── include/              # Конфигурация пинов и заголовочные файлы
│   ├── src/
│   │   └── main.cpp          # Графический движок Sprite, сервоприводы, WebSocket
